## How this folder works

- One file per topic, not one giant log — update the relevant file rather than appending
  forever.
- Frontmatter (`tags`, `updated`) on every note.
- Only durable, reusable facts belong here. Not task details, not ephemeral context, and
  never credentials.
- Add new topic files as they come up, and link them from this index.
